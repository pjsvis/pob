# Pandiculation as hysteretic search: telemetry for the path back to the datum

*Recorded 2026-09-23. A conceptual contribution from Peter, with sharpening. Touches the core argument of the book — prestress, floor work, pandiculation — and explains the n=1 biphasic observation (`2026-09-23-n1-floor-futon-biphasic.md`). Feeds `td-fdcbc2`.*

## The claim, as stated

> Because biological tissues exhibit hysteresis (the energy-dissipating lag between loading and unloading), the unloading path in phase space is fundamentally different from the loading path. Navigating back to the true energetic minimum — rather than getting trapped in a local, dysfunctional energy minimum — requires the system to search through a vastly larger combinatorial space of states.

> We pandiculate to get more telemetry so that we can search for the correct path back to the ground state.

## Why this matters: it is the mechanism-level "why" for the whole practice

If biological tissue were elastic, rest would suffice — remove the load, spring back to the datum. The universality of pandiculation across mammals, despite its energetic cost and despite sleeping sixteen hours a day, is the existence proof that passive relaxation does not return the system to its ground state. Under hysteresis the return is not a computation you can perform by going limp; it is a **search**. Pandiculation is that search as conserved by natural selection. The behaviour pays for itself precisely because hysteresis makes rest insufficient.

The probe structure supports the telemetry framing: pandiculation is contract-then-slow-release — a deliberate perturbation, with sensing during unloading, exactly the leg of the hysteresis loop where path information lives. Proprioceptive afferents fire on lengthening under load; the telemetry exists only while actuating. You cannot identify a hysteretic system without exciting it.

## Three sharpenings

1. **"Combinatorial" belongs to paths, not states.** The body's configuration space is continuous. Path-dependence is what makes it *effectively* combinatorial: each independent hysteretic element (fascicle groups, fascial layers, tonal setpoints) carries its own history, and distinct unload trajectories grow roughly factorially with the number of elements. The trajectory space is vast; the state space merely large.

2. **The "ground state" is not zero prestress.** A living tensegrity structure requires functional prestress; homeostatic tone is a feature. The search target is the species-typical prestress distribution, not the unloaded state. And the landscape is coupled mechano-neural: local minima include gamma-motor setpoints, which is why tone persists when mechanics alone would have relaxed. The search runs on the nervous system using mechanical telemetry — not gradient descent on mechanical energy in the naive sense.

3. **The search is local, not exhaustive.** With high-amplitude peaks, sparse point contact suffices — large gradient, obvious descent direction (the floor's bony contacts). With diffuse low-amplitude residuals, denser sampling is needed — larger contact surface, broader sweep (the futon). Instrument resolution follows gradient magnitude. This is the mechanistic explanation of the floor–futon biphasic observation: the search algorithm has entered a basin near the minimum and switched from global exploration to fine local probing.

## What this buys the book

- **Rest is insufficient, formally.** Under hysteresis, rest is not a return path; only active search returns the system to the datum. The floor-work practice is not comfort-seeking inverted — it is the search procedure, with the rigid floor as the fixed boundary datum against which error signals register.
- **Pandiculation is the sensing-while-actuating step.** Telemetry and search are the same act. The felt sense of "which way is release" is the afferent read of the local descent direction.
- **Surface choice is search strategy.** Point contact for peaks (sparse sampling, high gradient); distributed contact for foothills (dense sampling, low gradient). The n=1 futon data now has a mechanism.
- **A cross-domain echo worth noting:** the DCI finding (`2026-08-22-dci-paper-digest.md`) — capable agents win not by recalling more but by converting reached documents into verified evidence through fine-grained local probing. Pandiculation is the body's version: local probing within a promising basin, converting reached states into verified descent. Held as a metaphor, not an equivalence.
