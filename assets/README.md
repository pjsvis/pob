# Assets — Raw Material

Dump new source material here. Gemini transcripts, source documents, notes, sketches — anything that might feed the book or a blog piece but is not yet finished copy.

## Rules

- **The build ignores this directory.** Nothing here renders to `dist/` or appears on the site. You cannot derail the build by dropping a file here.
- **Tracked in git.** Assets are worth keeping as provenance; they are not gitignored.
- **Not a brief.** A brief (`briefs/*-brief-*.md`) is a plan to do something. An asset is material to process. Keep them separate: assets land here, briefs about assets land in `briefs/`.

## The loop

1. **Dump** the file here.
2. I **assimilate** it — read it, write a brief in `briefs/` proposing how to use it (which chapter, which part, or a standalone blog piece), with a placement decision.
3. **We assess** the brief together — use it, reject it, or reshape it.
4. If we use it, I **draft** the chapter or post from scratch (using the asset as source, not as text to rewrite — see `playbooks/style-playbook.md` Rule 11).
5. The asset stays here as the provenance record.
