# Diagram Demo

This page demonstrates the **Hybrid ASCII → SVG** pipeline with the colour‑enhanced primitives introduced in the recent update. The diagrams are rendered as SVGs during the build; the surrounding container adds scrollbars if the diagram exceeds the fixed viewBox.
