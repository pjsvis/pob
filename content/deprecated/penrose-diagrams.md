# Penrose Diagrams

:::newthought
Penrose diagrams are conformal maps that capture the causal structure of spacetimes while compressing infinite distances.
:::

## Penrose Triangle (ASCII)

```
   /\
  /  \
 /----\
 \    /
  \  /
   \/
   →
```

The arrow indicates the direction of the optical illusion; the shape is a classic "impossible" triangle.

## Penrose Staircase (ASCII)

```
   ┌─────┐
   │     │
   │  ──►│
   │     │
   └─────┘
```

The arrow inside the staircase illustrates the perpetual ascent illusion.

# Bio‑Tensegrity

:::newthought
Bio‑tensegrity models cells and tissues as a network of tension‑bearing cables and compression‑bearing rods. The notation below follows a simple node‑cable‑rod convention.
:::

## Simple Bio‑Tensegrity Diagram

```
   o───|───o
   │   │   │
   o───|───o
```

* `o` – compression rods (struts)
* `|` or `───` – tension cables (tendons)

This minimal diagram captures the essential tension‑compression interplay in a 2‑D tensegrity cell.
