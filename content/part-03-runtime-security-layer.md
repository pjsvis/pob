# Part III: The Runtime Security Layer

The body has a security system. It is not voluntary. It runs in the background, monitoring the afferent stream for threats, and when it detects one — real or perceived — it intervenes with muscle guarding, pain, and movement restriction. This is the runtime security layer.

These seven chapters describe how that system works and what happens when it goes wrong. The Frontier Scale: why the 1–10 scale is dead data, replaced by the four-zone map of systemic permission. The asymmetric constraint of one-sided habits. The floor datum where cramps are the alarm, not the fire. The patellar pulley where well-meaning stretching becomes destructive force. The amnesia paradox where copying the outward shape of good movement produces the opposite of good movement. The two faces of amnesia — somatic and practitioner — where a lost map is mistaken for a lost territory. The Cartesian projection error where flat, right-angled environments generate chronic shear in a body that was never designed to be flat or right-angled.

The thesis of this part is that the security system is rational. It is not malfunctioning when it causes pain. It is responding to an information deficit — the same deficit described in the staved finger essay. The pain is the guard, not the fire.
