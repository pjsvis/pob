The Mindset Shift: Designing for the Partnership
Developing MCP servers requires intentional design, considering two types of users: AI agent users and end users.
The core idea is to design for the partnership between the human user and the AI model, which acts as an assistant.
LLMs are not people, but treating them "like" people works better. They perform better when given purpose, clarity, and framing, similar to a human assistant.

Key Design Principles for MCP Servers
Traditional API Design (for Developers)
AI Agent Design (for LLMs/Assistants)
Humans browse docs to figure out what's possible.
LLMs rely on cues (tool descriptions) to decide what to do. Design for clear intent.
Humans infer required order (create → update → publish).
LLMs will happily start at publish unless explicitly told the allowed sequences. Describe allowed sequences.
Humans ask clarifying questions when underspecified.
LLMs often guess when something is ambiguous. Eliminate ambiguity with clear tool descriptions and examples.
A great MCP server acts as an abstraction layer, like a "website for LLMs," providing the best interface for the job.
