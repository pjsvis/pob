### The Cleanup Script (`cleanup_naughty_list.sh`)

```
#!/bin/bash

# TARGET_DIR defines where the logs are stored. 
# CHANGE THIS to the actual path (e.g., /var/log/naughty_list)
TARGET_DIR="/path/to/naughty_list_logs"

# 5 years in days (5 * 365 = 1825)
DAYS=1825

# Find and delete files
# -type f: looks only for files (ignores directories)
# -name "*.log": matches files ending in .log
# -mtime +$DAYS: matches files modified more than 1825 days ago
# -delete: deletes the files immediately (implies -depth)
# 2>/dev/null: silences all error messages (permission denied, etc.)

find "$TARGET_DIR" -type f -name "*.log" -mtime +$DAYS -delete 2>/dev/null

# Optional: verify exit status silently (0 = success)
exit 0

```


---

### Command Breakdown

- **`find "$TARGET_DIR"`**: This initiates the search in your specified directory. **Crucial:** Ensure you set `TARGET_DIR` correctly so you don't scrub the Good List by mistake.
- **`-mtime +1825`**: This filters for files modified more than 1,825 days (5 years) ago.
- **`-delete`**: This is the modern, efficient way to remove files found by `find`. It is faster than using `-exec rm`.
- **`2>/dev/null`**: This redirects "Standard Error" to the void. If the script hits a file it can't delete or a permission issue, it will say absolutely nothing, ensuring Santa remains asleep.
